# Распевка

Личный тренажёр вокала: распевки с нотной доской и распознаванием голоса, дыхание, тренажёр слуха, сочинение мелодий, теория и прогресс.

- Приложение: `app/` (Vite + React + TypeScript, pitchy, smplr).
- Каталог упражнений: `CATALOG.md`.
- Запуск локально: `cd app && npm install && npm run dev`.
- Выкладка: при пуше в `main` GitHub Actions собирает `app/` и публикует на GitHub Pages.
